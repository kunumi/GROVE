### Answer

# Summary

When handing over a finished system, software engineers must prepare documentation for the client (including source code documentation, functional specs, design, test suites, and operating environment details), for end users (safe/unsafe use, sensitive data protection, warnings), and for their own organization (requirements, design, tools, test specs, problems encountered). Documents should be retained at least as long as the software's life cycle or as required by regulations.
