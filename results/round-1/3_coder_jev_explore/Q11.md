What kinds of changes are made to software that is already in use, and what distinguishes each kind from the others?

### Answer

# Summary

Software that is already in use undergoes several distinct types of maintenance: corrective, preventive, adaptive, perfective, additive, and emergency. Each type addresses a different purpose—fixing faults, preventing future issues, adapting to environmental changes, enhancing quality, adding new features, or temporarily keeping a system operational.

# Guidelines

- **Corrective maintenance** fixes faults and latent defects found in operational software. (source: "Correct faults and latent defects")
- **Preventive maintenance** is performed to prevent future problems, such as security threats or technical obsolescence, before they cause failures. (source: "Prevent security threats" and "[SWEBOK excerpt 88f0df6eee63e400abe3]")
