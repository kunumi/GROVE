# Summary

The orders table suffers from data redundancy and inconsistency because customer name and address are repeated per row. Normalization—splitting data into related tables—removes this redundancy and inconsistency. However, this restructuring increases the number of tables and query processing time, a trade-off engineers must consciously manage.
