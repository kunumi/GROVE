### 2. Explicitly map every stakeholder concern, including cost and evolvability

Architectural concerns span a very wide set including "affordability, agility, … cost, … deployability, … evolvability, … maintainability, modifiability, … performance, … scalability, … sustainability." The team should produce an explicit list of these concerns for the proposed service split before attempting any evaluation.
