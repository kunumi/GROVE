**Summary checklist for the write-up:**

| Element | What to cover |
|---|---|
| Purpose & outcomes | Why the workflow exists and what success looks like |
| Inputs & outputs | What enters and exits at each hand-off |
| Activities & tasks | Named steps with actors, triggers, actions, and conditions |
| Controls & mechanisms | Policies, tools, skills, and infrastructure required |
| Responsibilities | RACI assignments for each step |
| Pre/postconditions | Valid start state and guaranteed end state per step |
| Maintenance plan | Who owns the document and how it is kept current |
| Form(s) | Natural language + graphical notation + formal/structured spec as needed by audience |
