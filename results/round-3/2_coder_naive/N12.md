## Guidelines for Measuring Numerical Discrepancy in Tests

### 1. Distinguish accuracy from precision before choosing a measure.
Accuracy and precision are distinct concepts. *Accuracy* is the closeness with which a computed value agrees with the true value, while *[SWEBOK excerpt e810dffb20b192f49532]. A fixed absolute threshold like 0.001 conflates these two ideas and does not scale with the magnitude of the value being tested.
(source: "[SWEBOK excerpt b586fdd39148fb34c49b].")

---

### 2. Use **relative error**, not absolute error, as the primary acceptance criterion.
The absolute error `|x* − x|` does not reflect the magnitude of the values involved. The relative error — [SWEBOK excerpt a79fa5653f2133ab94aa] the true value, `|x* − x| / |x|` — scales with the magnitude and is therefore more appropriate. For example, an absolute error of 1 is negligible for a true value of 1,000,001 (relative error = 10⁻⁶) but catastrophic for a true value of 11 (relative error ≈ 0.1). Fixed thresholds such as 0.001 behave in exactly this misleading way.
(source: "[SWEBOK excerpt 297dadd84958fa3cc461].")

---

### 3. Note that relative error is undefined when the true value is zero.
The relative error formula `|x* − x| / |x|` assumes `x ≠ 0`. When the expected value is zero or very close to zero, relative error is not defined or is unreliable, so a different strategy (such as a small absolute tolerance or a combined absolute-plus-relative tolerance) must be used for those cases.
(source: "[SWEBOK excerpt aeccdce49a2a8ce6b6d1].")

---

### 4. Interpret the relative error in terms of **significant decimal digits** to know how many leading digits are correct.
[SWEBOK excerpt 1444412c8f024ffe382c] less than `5 × 10^(−k−1)`. This directly tells you how many leading (non-zero) digits of the computed result match the true value, giving a meaningful measure of trustworthiness regardless of scale.
(source: "[SWEBOK excerpt e98f68a3670db66a99c0]⁻ᵏ⁻¹. [SWEBOK excerpt 60ef169083bccf6d8b7d].")

---

### 5. Recognize that significant digits are the digits known to be correct, with one uncertain digit included.
When specifying a test tolerance in terms of significant digits, understand that the last stated digit is typically uncertain. For instance, a measurement of 15.47 mm with ±0.01 mm error has three significant digits, while 15.5 mm with ±0.5 mm error has only two. Tolerances in numerical tests should be chosen to reflect the precision of the computation, not an arbitrary constant.
(source: "[SWEBOK excerpt f7f3a65aa84a447e276f].")
