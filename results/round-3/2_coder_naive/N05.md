## Guidelines for Preserving the Ability to Reproduce a Shipped Executable

### 1. Place all Software Configuration Items (SCIs) under SCM control — including source code, executable code, code libraries, tools, and build documentation.

### Summary

The root cause of this team's predicament is that one or more of the above SCM practices were not followed at the time of the original release. SWEBOK makes clear that the ability to reproduce a previous build requires deliberate, up-front preservation of: the source code, the toolchain (compiler and build scripts), the external dependencies, the binary outputs, the SBOM, and documentary records such as the VDD — all versioned and stored under formal SCM control.
