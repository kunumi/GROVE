### Answer

# Summary

A routine can make its assumptions explicit and guard against invalid inputs by applying Design by Contract (preconditions/postconditions), using assertions to check input values at runtime, and employing defensive programming techniques such as validating all inputs and deciding how to handle bad data through error/exception handling strategies.
