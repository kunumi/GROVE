### Question

We are planning a project that depends on a third-party API nobody on the team has used and on a performance target we may not be able to reach. How should we handle these things that could go wrong, both when planning the work and while it is under way?

### Answer

# Summary

When a project depends on an unfamiliar third-party API or faces uncertain performance targets, teams should systematically identify and analyze these risks upfront, build mitigation strategies into the plan, and continue monitoring risk throughout the project lifecycle—using prototypes, simulations, and regular reviews to detect problems early and trigger corrective action when thresholds are exceeded.
