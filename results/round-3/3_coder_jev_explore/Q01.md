### Answer

# Summary

For a component whose behavior depends on its current state and received events, use state transition testing: derive positive test cases from each defined transition in a state model, and derive negative test cases from state/event combinations not present. BDD scenarios and finite-state machine models can also guide systematic test case derivation.

# Guidelines

- Represent the component using a state (transition) diagram or statechart to show how behavior changes based on current state and response to input events. (source: "[SWEBOK excerpt 92fdaa1f7412be44eba6].")
