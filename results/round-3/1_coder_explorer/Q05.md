### Question

How should test inputs be chosen for a function that accepts numeric values within a valid range?

Answer with a list of guidelines. After each guideline, cite the source it comes from: the path of the SWEBOK file if you have it, otherwise a verbatim quote of at least 8 words from the passage, in the form (source: ...).

### Answer

# Summary
SWEBOK v4 describes a layered strategy for choosing test inputs for a numeric function with a valid range. The core techniques are: (1) **equivalence partitioning** — divide the input domain into valid and invalid classes and pick at least one representative from each; (2) **boundary value analysis** — test at and near the min/max boundaries, since faults cluster there; (3) **robustness testing** — also test values outside the valid range; and (4) **exception forcing** — specifically probe for overflow, underflow, and other numeric error conditions. Random testing can supplement these deterministic approaches.
