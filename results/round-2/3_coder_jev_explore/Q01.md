How should I derive test cases for a component whose behavior depends on its current state and on the events it receives?

### Answer

# Summary

When a component's behavior depends on its current state and received events, test cases should be derived using state transition testing techniques. Positive test cases cover each defined transition; negative test cases cover invalid state/event combinations. State (transition) diagrams visualize how behavior changes based on state and input events, and tools can assist in generating these test cases.

# Guidelines

- Use state transition testing techniques, which represent the system under test (SUT) with a finite-state machine, to derive test cases for state-dependent components.
