# Guidelines
- Design error-handling so it directly affects software's ability to meet correctness and robustness requirements: the choice of how errors are handled has real consequences on non-functional attributes, so it must be a deliberate design decision. (source: root/Software Construction Techniques and Practices/Contract Design and Error Handling Strategies/Error Handling, Exception Handling, and Fault Tolerance.md) [JEV 0.97]
- Consider a range of error-handling techniques suited to the situation, including: [SWEBOK excerpt fab09da3601a283baf81]. (source: root/Software Construction Techniques and Practices/Contract Design and Error Handling Strategies/Error Handling, Exception Handling, and Fault Tolerance.md) [JEV 0.96]
- Use exceptions [SWEBOK excerpt faa5a8a24fd72e5b9ae1]: a routine throws an exception when it detects an error, and a try-catch block catches it, either handling the erroneous condition or returning control to the caller. (source: root/Software Construction Techniques and Practices/Contract Design and Error Handling Strategies/Error Handling, Exception Handling, and Fault Tolerance.md) [JEV 0.98]
- Design exception-handling policies carefully by following common principles: include [SWEBOK excerpt e56492e15b911c91a518], avoid empty catch blocks, know which exceptions library code throws, consider building a centralized exception reporter, and standardize the program's use of exceptions. (source: root/Software Construction Techniques and Practices/Contract Design and Error Handling Strategies/Error Handling, Exception Handling, and Fault Tolerance.md) [JEV 0.98]
- Use assertions (executable predicates placed in a program) as an alternative or complement to exception handling for checking for errors, especially in high-reliability programs; assertions are particularly useful for flushing out mismatched interface assumptions and errors introduced by code modifications. (source: root/Software Construction Techniques and Practices/Contract Design and Error Handling Strategies/Error Handling, Exception Handling, and Fault Tolerance.md; root/Software Construction Techniques and Practices/Assertions and Design by Contract in Programming.md; root/Software Construction Techniques and Practices/Parameterization, Templates, Generics, and Assertions.md) [JEV 0.90]
- Apply Design by Contract (preconditions and postconditions on each routine) to precisely specify the semantics of a routine and clarify its expected behavior, thereby reducing the chance of erroneous conditions arising in the first place. (source: root/Software Construction Techniques and Practices/Contract Design and Error Handling Strategies/Design by Contract and Defensive Programming.md; root/Software Construction Techniques and Practices/Assertions and Design by Contract in Programming.md) [JEV 0.92]
- Apply defensive programming to protect routines from invalid inputs: check the values of all input parameters and decide explicitly how bad inputs will be handled before they can propagate or cause errors deeper in the system. (source: root/Software Construction Techniques and Practices/Contract Design and Error Handling Strategies/Design by Contract and Defensive Programming.md) [JEV 0.97]
- Apply fault tolerance strategies for critical software: detect errors and then recover from them or contain their effects if recovery is not possible. Common [SWEBOK excerpt 5d2639acdc83c4d675a4]. (source: root/Software Construction Techniques and Practices/Fault Tolerance Techniques and Executable Models.md) [JEV 0.96]
- Compile assertions into the code at development time and compile them out of the code for production so they do not degrade runtime performance. (source: root/Software Construction Techniques and Practices/Assertions and Design by Contract in Programming.md) [JEV 0.97]
- Treat error-handling and defensive programming as construction quality techniques, alongside unit testing, integration testing, debugging, inspections, and static analysis, since [SWEBOK excerpt 20a46eeceea816b903c0] including security vulnerabilities. (source: root/Software Construction Techniques and Practices/Construction Quality Techniques and Practices.md) [JEV 0.96]
