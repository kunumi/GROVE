### Question

Beyond code coverage, how can I evaluate whether my test suite is good at detecting faults?

### Answer

# Summary
SWEBOK v4 identifies several methods for evaluating test suite fault-detection quality beyond code coverage. The primary approach is **mutation testing**, which introduces small syntactic variants of the code ("mutants") and measures the **mutation score** (ratio of killed mutants to total mutants generated) as a direct indicator of test suite strength. Complementary techniques include **fault injection**, **fault density measurement**, **reliability growth models**, and **operational-profile-based testing**, along with using **fault taxonomies** to focus test case design on historically prevalent fault types.
