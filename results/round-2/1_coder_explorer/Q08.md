# Summary
After every system change, teams should perform **regression testing** — selective retesting [SWEBOK excerpt 021f9937eefeac172cee] system still meets its specified requirements. Rather than re-running every test, teams should *select and minimize* their test cases, *prioritize* them for maximum fault detection, and *automate* the suite. The right moment to run regression tests spans all test levels (unit through acceptance), but canonically occurs [SWEBOK excerpt 0f6027292d0f7e6a203b]; in Agile, DevOps, and TDD contexts it is performed continuously.
