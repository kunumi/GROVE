### Question

What general practices should developers follow when writing code so that attackers cannot exploit it?

### Answer

Based on the SWEBOK Guide, here are the general practices developers should follow when writing code to prevent exploitation by attackers:

1. **Validate all input.** Input validation is listed as the top security practice to adopt.
(source: Software Security Engineering and Professional Practice/Secure Software Development Standards and Practices/Top 10 Software Security Practices.md)

2. **Heed compiler warnings.** Compiler warnings often flag constructs that can lead to vulnerabilities.
(source: Software Security Engineering and Professional Practice/Secure Software Development Standards and Practices/Top 10 Software Security Practices.md)

3. **Architect and design for security policies.** Security must be planned at the architectural level, not added as an afterthought.
(source: Software Security Engineering and Professional Practice/Secure Software Development Standards and Practices/Top 10 Software Security Practices.md)

4. **Keep it simple.** Complexity increases the attack surface and the likelihood of flaws.
(source: Software Security Engineering and Professional Practice/Secure Software Development Standards and Practices/Top 10 Software Security Practices.md)

5. **Default deny.** Access should be denied by default, granting it only when explicitly permitted.
(source: Software Security Engineering and Professional Practice/Secure Software Development Standards and Practices/Top 10 Software Security Practices.md)
